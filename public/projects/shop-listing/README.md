Images keep their **original aspect ratio** — open `shop.ts` and set
`width` / `height` to match your actual file dimensions (in pixels) so
the panel doesn't crop or letterbox awkwardly. Also update `title` and
`brief` for each to describe the real listing. Add, remove, or reorder
entries in the `SHOP_ITEMS` array; the gallery updates automatically.
