# Profile portrait

Add your portrait image here as:

```
profile.jpg
```

Recommended: a vertical or square crop, at least 1200px on the short side.
It's displayed in black & white (grayscale filter is applied in code), so
a sharp, well-lit, high-contrast source photo works best.

Until this file exists, the hero section shows a placeholder ink panel
instead of a broken image — the site still works, it just needs the photo.
